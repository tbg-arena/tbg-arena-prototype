# TBG ARENA 시안 생성기 (Figma 플러그인)

HEX 팔레트로 TBG ARENA 대표 화면 5개(홈 · 필살기 · 콜아웃 · 랭킹 · 커리어)를 Figma에 그려 주는 개발용 플러그인입니다.

## 설치

1. Figma **데스크톱 앱**에서 디자인 파일 열기
2. 메뉴 → Plugins → Development → **Import plugin from manifest…**
3. 이 폴더의 `manifest.json` 선택
4. Plugins → Development → **TBG ARENA 시안 생성기** 실행

## 사용

- 한 줄에 시안 하나: `이름 | HEX: #xxxxxx #xxxxxx …`
- 색 역할(배경 · 글자 · 메인 · 포인트 · 완료 · 상대 코너 · 보조 선)은 자동으로 나뉘고, 색 아래 선택 상자에서 바꿀 수 있습니다.
- **시안 만들기** → 지금 페이지의 기존 내용 아래쪽에 시안마다 섹션 하나(컬러 시스템 시트 + 화면 5개 + “왜 좋은가” 카드)가 생깁니다.
- “Figma 변수로 연결”을 켜면 색이 `color/*` 변수에 묶입니다. 프레임의 변수 모드만 바꾸면 다른 시안으로 바뀝니다.
  요금제 모드 수 제한에 걸리면 시안마다 컬렉션을 따로 만듭니다.

## 서체

- 본문: Pretendard → Noto Sans KR → … 순서로 설치된 것을 씁니다.
- 숫자 · 라벨: Galmuri11 / DungGeunMo 같은 한글 도트 서체가 있으면 그것을, 없으면 Silkscreen 같은 영문 도트 서체를 씁니다(한글은 본문 서체로).
- 캐릭터는 자리표시 도트 복서입니다. 실제 스프라이트로 교체하세요.

## 버튼 · 안내 스타일

- **차분하게(기본)**: 버튼 · 안내 배너 · 선택 강조에 빨강을 쓰지 않습니다. 버튼은 흰 면 + 회색 하드 섀도, 배너는 카드 면 + 흰 테두리 + 포인트 태그, 탭 알림 숫자는 포인트 색. 빨강은 글러브 · 활성 탭 표시 · 섹션 네모 · KO/연승 태그에만 남습니다.
- **강조**: 이전 시안. 버튼 · 배너 · 선택 그림자가 메인 빨강입니다. 두 버전을 나란히 비교할 때 쓰세요.
